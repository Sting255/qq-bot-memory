# 语音参考音频放这里

本目录不包含任何音频文件——音色样本需要你自己准备。

## 为什么

仓库里不分发角色配音素材（版权原因）。TTS 用 voiceclone 模式时，
需要一个 20 秒左右的音频作为音色参考。

## 怎么准备

1. 录一段（或找一段你有权使用的）**20 秒以内**的人声
2. 建议：单人说话、少背景音、语速自然、内容随意
3. 转成 `mp3` 或 `wav`，放到本目录，例如 `resources/voice/my-voice.mp3`
4. 在 `config.yaml` 里指向它：

```yaml
tts:
  enabled: true
  sample_path: "resources/voice/my-voice.mp3"
```

5. 重启服务

## 说明

- 时长超过 20 秒不会报错，但音色还原度会下降
- 文件缺失时 TTS 自动不可用，文字回复不受影响
- 音频文件已在 `.gitignore` 里排除，不会误提交
